# 管理员面板文档

## 访问权限

仅 `role === "admin"` 的用户可访问 `/admin/index.html`。非管理员访问时自动跳转首页。

管理员账号在数据库初始化时自动创建（`backend/db/init.js`），用户名固定为 `admin`，密码通过环境变量 `ADMIN_PASSWORD` 设置。

│          │                                      │

移动端（≤768px）侧边栏变为顶部横向标签栏。

## 功能模块

### 1. 仪表盘

路径：`/admin/index.html`，默认显示。

调用 `GET /api/admin/stats` 获取统计数据，展示四个卡片：

| 指标 | 说明 |
|------|------|
| 用户总数 | 注册用户数量 |
| 播客总数 | 所有状态的播客数量 |
| 待审核 | status = 'pending' 的播客数量 |
| 评论总数 | 所有评论数量 |

### 2. 用户管理

调用 `GET /api/admin/users`（分页）获取用户列表。

表格列：

| 列 | 说明 |
|------|------|
| ID | 用户 ID |
| 用户名 | 可点击跳转到用户主页 |
| 角色 | 管理员（紫色）/ 用户（绿色） |
| 状态 | 正常（绿色）/ 封禁（红色） |
| 注册时间 | 格式化后的时间 |
| 操作 | 封禁/解封按钮（管理员无操作） |

**封禁/解封**：调用 `PUT /api/admin/users/:id/status`，body 为 `{ status: "banned" }` 或 `{ status: "active" }`。封禁后用户无法登录。

### 3. 内容审核

调用 `GET /api/admin/podcasts`（分页）获取所有播客。

表格列：

| 列 | 说明 |
|------|------|
| ID | 播客 ID |
| 标题 | 播客标题 |
| 作者 | 可点击跳转到用户主页 |
| 音频 | 内嵌音频播放器（可试听，preload=none） |
| 状态 | 待审核（黄色）/ 已通过（绿色）/ 已拒绝（红色） |
| 发布时间 | 格式化后的时间 |
| 操作 | 通过/拒绝按钮 |

**审核操作**：调用 `PUT /api/admin/podcasts/:id/status`，body 为 `{ status: "approved" }` 或 `{ status: "rejected" }`。

审核通过或拒绝时，系统自动向播客作者发送通知：
- 通过：`"你的播客「<标题>」已通过审核"`，链接到播客详情页
- 拒绝：`"你的播客「<标题>」未通过审核"`，链接到我的播客页

## 与普通前端的区别

| 特性 | 普通前端 | 管理面板 |
|------|----------|----------|
| 访问控制 | 登录用户 | 仅管理员 |
| 数据范围 | 已审核播客 | 所有状态的播客和用户 |
| 操作 | 点赞/评论/收藏/删除自己内容 | 封禁用户、审核内容 |
| 布局 | 单栏内容 | 侧边栏 + 内容区 |
| 分页 | 每页 10-20 条 | 每页 20 条 |
