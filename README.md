# Podcast Platform (播客平台)

一个类似微博的播客发布平台，支持用户注册登录、发布播客音频、动态流互动（点赞/评论）、管理员后台管理。

## 功能特性

- 用户注册 / 登录
- 发布播客（音频上传）
- 动态流（类似微博时间线）
- 点赞、评论互动
- 管理员后台（用户管理、内容审核）

## 开发流程

| 轮次 | 类型 | 描述 | PR |
|------|------|------|-----|
| 1 | feat | 初始版本 | #1 |
| 2 | refactor | 代码质量优化 | #2 |
| 3 | feat | 用户体验优化 | #3 |
| 4 | feat | 功能增强 | #4 |
| 5 | fix | Bug修复 | #5 |

## 技术栈

- 后端: Node.js + Express
- 前端: HTML + CSS + JavaScript
- 数据存储: SQLite / JSON file
- 文件上传: multer
